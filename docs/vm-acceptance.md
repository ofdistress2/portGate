# Матрица испытаний перед эксплуатацией

Матрица дополняет [двухдневный пилот](validation.md). Для испытаний используйте отдельные ВМ, снимки и консольный доступ.

| Среда | Проверки |
|---|---|
| Server 2016/2019/2022 Desktop Experience | Установка SCM, автозапуск, GUI, DPI 100/150/200%, Named Pipe, SYSTEM cleanup |
| Server Core 2016/2019/2022 | Хост без Desktop Runtime, полный CLI и задачи |
| Windows 10/11, PowerShell 5.1 | Сгенерированный файл, RemoteSigned/корпоративные политики, IPv4/IPv6, запуск mstsc |
| Домен | GPO Allow/Block, запрет local merge, повторное применение политики, отсутствие ложного успешного статуса |
| Firewall | Нестандартный RDP-порт, TCP/UDP, Any/диапазон портов, TermService, стороннее правило, смена профиля |
| Первое применение | Падение после каждой стадии, откат через 120 сек/при перезагрузке, новый WTS-сеанс, постороннее изменение исходных правил |
| Допуски | Срок, отзыв/ротация/истечение ключа, общий IP клиентов, гонка очистки и выдачи, потеря UDP, повтор RESULT |
| Сбои | Kill службы, восстановление SCM, остановка планировщика, повреждение состояния, перевод часов, заполнение диска |
| Поставка | Каталог с пробелами, ACL, сохранение/восстановление политики при удалении, отсутствие оставшихся задач |
| Нагрузка | Поток невалидных/валидных пакетов, лимиты памяти/правил/кэша и объёма журнала |

Внешнюю доступность проверять с доверенного и недоверенного IP через новое TCP-подключение, а не по существующей RDP-сессии. Не использовать рабочий компьютер как стенд миграции Firewall.
