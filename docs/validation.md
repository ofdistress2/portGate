# Проверки portGate 1.0.11

## Двухдневный пилот

Версия 1.0.11 установлена на действующем Windows RDP-сервере и продолжает работать. В ходе пилота проверены установка, остановка, перезапуск и откат. Эти результаты относятся к конфигурации, на которой проходил пилот.

## Проверки сборки

Штатный набор `build.ps1` проверяет в том числе запись состояния, обработку протокола, план изменения правил и откат с имитацией брандмауэра, а также сгенерированный клиент в Windows PowerShell 5.1 через UDP loopback. Проверки CI и пилот дополняют друг друга.

## Дополнительные окружения

Версии Windows Server 2016, 2019 и 2022 входят в перечень целевых платформ. [Матрица ВМ](vm-acceptance.md) перечисляет сценарии для Server Core, групповых политик, сбоев и обновлений в отдельных окружениях. Точные параметры пилотного сервера здесь не публикуются.

На macOS используется только клиентский пропуск. Проверка генерации пропуска входит в тесты Windows. Компиляцию в `.scpt` и запуск в Редакторе скриптов выполняют на целевой версии macOS.
