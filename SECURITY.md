# Сообщения об уязвимостях

Для версии 1.0.11 используйте [приватный отчёт GitHub Security](https://github.com/ofdistress2/portGate/security/advisories/new). Укажите версию, затронутый компонент и протокол воспроизведения в тестовой среде. Перед отправкой удалите действующие ключи, экспортированные пропуска и данные рабочей инфраструктуры.

Обычные ошибки установки и использования можно описать в [GitHub Issues](https://github.com/ofdistress2/portGate/issues).
