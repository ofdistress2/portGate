# Сообщения об уязвимостях

Для версии 1.0.14 используйте [приватный отчёт GitHub Security](https://github.com/ofdistress2/portGate/security/advisories/new). Укажите версию, затронутый компонент и протокол воспроизведения в тестовой среде. Перед отправкой удалите действующие ключи, экспортированные пропуска и данные рабочей инфраструктуры.

Обычные ошибки установки и использования можно описать в [GitHub Issues](https://github.com/ofdistress2/portGate/issues).

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ofdistress2/portGate/security/advisories/new) for portGate 1.0.14. Include the affected version and component, plus reproducible steps from a test environment. Remove active keys, exported passes, and production infrastructure details before submitting. Report general installation or usage problems in [GitHub Issues](https://github.com/ofdistress2/portGate/issues).
