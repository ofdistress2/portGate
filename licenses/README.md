# Компоненты Microsoft .NET

Автономный ZIP включает .NET Runtime и Windows Desktop Runtime. В поставку также входят библиотеки System.ServiceProcess.ServiceController и System.Diagnostics.EventLog. Их лицензия MIT приведена в `dotnet-MIT.txt`. При публикации сборка добавляет в эту папку файлы лицензий и уведомлений из фактически использованных NuGet-пакетов.
